Pomodoro Timer

A desktop Pomodoro timer built with Python and Tkinter to help you focus using the Pomodoro Technique: work in short focused sessions separated by breaks.

Features
- Countdown timer displayed in a Tkinter window
- Start and Reset controls
- Automatic switching between work and break sessions
- Checkmarks tracking completed work sessions

## What I learned
- Building GUIs with Tkinter
- Scheduling and countdowns with `after()` instead of blocking loops
- Managing application state across timer sessions
